Wynncraft build guides

How builds work in Wynncraft, explained with the same formulas the Build Recommender calculates with. Every number on these pages - the skill point curve, effective HP, damage, mana - comes from the calculator, which follows Wynnbuilder's formulas and item data for game version 2.2.4.

Start with how the recommender picks a build if you use the tool, or with skill points and effective HP if you want to understand builds in general. The class guides cover the fifteen archetypes and list the guide builds for each.
